# スクラップ重量管理アプリ

工場のスクラップ重量を日次で記録し、品目マスター・初品実測重量・McFrameの完成品数量・月次在庫入力と組み合わせて、**理論スクラップとスクラップ売却数量のズレ**を管理する業務アプリです。

サーバー不要の静的Webアプリです。`index.html` をブラウザで開くだけで動作します(社内ファイルサーバー配置・イントラWebサーバー・GitHub Pages いずれも可)。データはブラウザの localStorage に保存されます。

## 機能と要件対応

| # | 要件 | 画面 |
|---|------|------|
| ① | スクラップ記録様式のアプリ化と集計 | 「日次記録」タブ(紙の日次記録票と同じ構成: 朝礼確認/日中記録/終礼集計/備考 + 月間集計・CSV出力) |
| ② | 品目別マスターの登録(子図番での呼び出し、KEYはMcFrameの設定) | 「品目マスター」タブ(KEY = 管理図番 + 製造場所CD を自動生成。子図番・親図番・品名で検索。CSV取込/出力) |
| ③ | 毎日生産した初品の単品完成品重量の測定 | 「初品重量測定」タブ(品目を検索・選択して実測重量を登録。履歴管理) |
| ④ | McFrameから完成品数量の取り込み(③との集計により完成品重量の算出) | 「McFrame取込」タブ(CSV取込。完成重量 = 加工数 × 単品完成重量。初品実測を優先、未測定はマスター理論値) |
| ⑤ | 月初在庫、購入数量、スクラップ売却数量の入力 | 「月次入力」タブ(区分別=銅条/銅管/その他の月初在庫・購入重量、売却数量を年単位で入力) |
| ⑥ | ①と⑤のスクラップ売却数量との突合 | 「照合ダッシュボード」タブ(売却数量 − 日次記録合計、差異率) |
| ⑦ | ⑤から算出した理論スクラップと⑥との突合 | 「照合ダッシュボード」タブ(売量vs理論、日次記録vs理論、年間推移) |

## 計算式(月次集計Excelの式を踏襲)

- **使用量(在庫法)** = 月初在庫 + 購入重量 − 翌月月初在庫
- **使用量(構成法)** = Σ(加工数 × 構成重量) ※翌月在庫が未入力の場合のフォールバック
- **完成重量** = Σ(加工数 × 単品完成重量) ※単品完成重量は初品実測値(対象月末以前の最新)を優先、未測定はマスターの理論値
- **理論スクラップ** = 使用量 − 完成重量
- **⑥ 差異** = スクラップ売却数量 − 日次記録スクラップ合計
- **⑦ 売量vs理論** = スクラップ売却数量 − 理論スクラップ

> 前提: 使用量(構成法)は「加工数 × 構成重量」の単純積で計算しています(構成数の乗算は行いません)。運用と合わない場合は `js/calc.js` の `monthlyItemRows` を調整してください。

## CSV取込フォーマット

### 品目マスター (「品目マスター」→ CSV取込)

1行目に見出しがあれば列順は自由です(見出し例: 管理図番, 品名, KEY, 区分, 親図番, 親品名, 子図番, 子品名, 単位, 構成重量, 完成重量(理論), 製造場所CD, 製造場所名, 工場)。KEY 未指定時は 管理図番+製造場所CD から自動生成します。サンプル: [`samples/品目マスター_サンプル.csv`](samples/品目マスター_サンプル.csv)

### McFrame 完成品数量 (「McFrame取込」→ CSV取込)

以下のいずれかの形式(1行目ヘッダー可):

```csv
KEY,年月,加工数
303226400Z023000,2026-08,18899
```

```csv
管理図番,製造場所CD,年月,加工数
303226400,Z023000,2026/08,18899
```

年月は `2026-08` / `2026/08` / `202608` / 日付(`2026/08/15`)に対応。同じ年月×KEYは上書きされます。文字コードは UTF-8 / Shift_JIS どちらも自動判定します。サンプル: [`samples/mcframe_サンプル.csv`](samples/mcframe_サンプル.csv)

## データの保存とバックアップ

- データは**ブラウザごと**(localStorage)に保存されます。端末やブラウザを変えるとデータは共有されません。
- 「設定」タブから全データを JSON でバックアップ/復元できます。**定期的なバックアップ取得と共有フォルダ保管を推奨します。**
- 複数端末での同時運用が必要になった場合は、バックエンド(データベース)化を検討してください。

## 記録保管期間

日次記録3年 / 月次集計5年(各集計画面のCSV出力を月次で保管してください)。
